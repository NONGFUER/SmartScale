- **修复 4G 关闭时开关延迟 7s 才关闭的问题（方案C：CellDisabling 枚举）**：
  根因：`disableCellular()` 原来设状态为 `CellSearching`，QML 的 `onCellularStatusChanged` 把 `CellSearching` 映射为"已开启"（`>= Searching && <= Roaming`），导致点击关闭后开关被弹回"开"，直到命令完成后才真正落定 Disabled。
  修复：新增枚举值 `CellDisabling = 7` + 成员变量 `m_cellularDisablePending`；`disableCellular()` 改设 `CellDisabling` 并开启关闭挂起窗口；`refreshCellularStatus()` 在挂起窗口内保持 `CellDisabling` 不回退 Disabled；`onCellularOpFinished` 成功分支和 15s 超时均清标志并落定 `CellDisabled`；QML 两处绑定（`onCellularStatusChanged` + `onOpened`）排除 `CellDisabling`。
  效果：点击关闭 → 图标立即断网 + 开关立即关，不再被弹回。涉及文件：NetworkManagerService.h（枚举+成员）、NetworkManagerService.cpp（5处）、CellularDialog.qml（2处）。read_lints 零错误。
- **修复 4G 关闭后开关仍不立即关闭的残留问题**：
  根因：`ip link set eth1 down` 只把接口状态切为 DOWN 但不立即清除已分配 IP；`refreshCellularStatus()` 调用 `hasGlobalIPv4()` 仅检查 QNetworkInterface 是否报了 IP，未检查接口是否 UP，导致 IP 残留时误判为 Connected 并 emit `CellConnected` 把开关弹回"开"，同时提前清除 `m_cellularDisablePending` 挂起窗口。
  修复：`hasGlobalIPv4()` 新增 `IsUp` 前置条件——接口非 UP 时即使有 IP 也返回 false。
  涉及文件：NetworkManagerService.cpp（hasGlobalIPv4 函数，+3行）。read_lints 零错误。
