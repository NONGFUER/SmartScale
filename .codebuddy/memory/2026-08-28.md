# 2026-08-28

## AI 4K 抓帧仍出 540×540 的修复（时序 bug）
- 现象：识别图仍是 540×540 而非 1080×1080。排查：`v4l2-ctl -d /dev/video0 --list-formats-ext` 确认主摄支持 MJPG 3840×2160@30fps，硬件无问题。
- 根因：`QCamera::stop()` 异步，原实现立刻 `setCameraFormat()` 被忽略 → 读回仍 1080p → m_aiTargetSize 错设为 1080p → sink 残留旧帧尺寸"匹配" → 抓 1080p → 裁 540×540；超时兜底路径也无尺寸校验同样抓旧帧。
- 修复（CameraController.cpp/h）：
  - 新增 `applyAiCaptureFormat(int attempt)`：stop() 后延迟 300ms 再下发 4K 格式+start；读回校验非 4K → 500ms 后重试一次 → 仍失败 setAiError("摄像头高清模式未就绪，请重试")+切回，不再静默降级。
  - `grabAiCaptureFrame` 加尺寸守卫：sink 帧尺寸 != m_aiTargetSize 坚决不抓，重新挂起等待。
  - 等 4K 帧超时 2s→5s（模式协商+MJPEG 首帧解码慢）。
  - `_processCommon` 保存 cp0.jpg 时打尺寸日志（验证用：`裁剪图 cp0.jpg 尺寸: 1080 x 1080（源帧 3840x2160）`）。
- 教训：QCamera stop/setFormat/start 时序必须等 stop 落定；抓帧前校验帧尺寸防止抓到切换前残留帧。
