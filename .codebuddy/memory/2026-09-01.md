# 2026-09-01

## 主摄 1200 万像素黑屏排查
- 现象：用户把 `m_mainWidth/Height` 改为 4000×3000 后预览黑屏。
- 真凶：运行的旧进程（pid 1318，17:04 启动，exe deleted）设的是 8000×6000 MJPG@5fps（v4l2-ctl 读回证实），17:13 新编译的 4000×3000 版本未重启生效。8000×6000 RGBA 纹理 192MB 超 GPU 4096×4096 纹理上限 → VideoOutput 黑屏。
- 主摄能力（v4l2-ctl -d /dev/video0）：MJPG 8000×6000@5 / 6000×4000@5 / 4000×3000@20 / 3840×2160@30 / 2592×1944@30；YUYV 仅 ≤1080p@5。
- 纹理带宽估算：4000×3000@20fps ≈ 1GB/s 上传，Pi 上易掉帧；折中推荐 2592×1944@30fps（20MB/帧）。
- 环境：Qt 6.8.2（FFmpeg 多媒体后端），jpegdec 可用。
- 排障套路：黑屏先 `fuser /dev/video0` + `v4l2-ctl --get-fmt-video` 看实际生效格式，再对照进程启动时间与二进制编译时间（exe deleted = 跑的是旧二进制）。
