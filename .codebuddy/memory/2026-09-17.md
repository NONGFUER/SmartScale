### 模型实测规格（本地 python onnxruntime 跑通）
- 输入 `x` = [N, 3, 48, W]（W 动态，8 倍下采样，W=192→T=24）
- 输出 `fetch_name_0` = [N, T, 18385]，**已内置 softmax**（每行和=1.000）
- 字典 18384 行：第 1 行是 U+3000，末尾含空行；类别数 = 18384 + 1(CTC blank) = 18385 ✔
- 映射：输出索引 i>0 → 字典第 i 行（dict[i-1]）
- 预处理：`(v/255-0.5)/0.5`，NCHW float32
- 单次推理 ≈ 23ms（本机 aarch64，对应 24 个时间步）
- 识别验证：「土豆/西红柿/白菜/鸡胸肉/盐/鸡蛋」全对，置信度 0.99+
- 形变鲁棒性（旋转±14°/错切±0.18/缩放0.85-1.15，123 个食材字）：top-1 = 98.4%（仍是印刷体字形，仅证明预处理+解码抗几何形变）

### 新增
- `src/ai/PpocrRecognizer.{h,cpp}`：QObject 单例（QML 侧 `SmartScale.Hwr/Ppocr`）。模型/字典懒加载（互斥串行，`m_loadAttempted`+锁保证并发调用阻塞等待）、字典读取 18383 行后按模型输出维度补 `" "`；`strokesToImage()`（QPainter 白底黑墨、单字方形留白 0.16/长条 0.04、笔宽 = 墨迹边长×0.055）、`preprocess()`（灰度→高 48 等比→宽 clamp 48..640→(v/255-0.5)/0.5→3 通道）、`decode()`（CTC 贪心 + 峰值时刻 top-N 候选；置信度 <0.30 丢弃）；`Q_INVOKABLE recognizeStrokesQml()` 供调试弹窗。
- `src/ai/HandwritingInputMethod.{h,cpp}`：`QVirtualKeyboardAbstractInputMethod` 子类（**只用公开头文件**，无私有依赖）。`patternRecognitionModes()={Handwriting}`、`inputModes()` zh 前缀含 ChineseHandwriting 否则 Latin/Numeric/Dialable、`traceBegin/traceEnd` 收集点集、抬笔 380ms 去抖（`startTimer`）、QtConcurrent 工作线程识别（`QFutureWatcher` + `m_generation` 代际丢弃过期结果）、识别开始即清墨迹（避免抢写时新旧笔画混墨）、新笔画自动提交上一字（连续手写）、候选栏 top-5 + `setPreeditText`、点候选 `commit(text)`、数字/拉丁模式过滤候选。
- `src/ui/components/HandwritingBridge.qml`：`keyboard.setHandwritingMode()` 开关 + `InputContext.inputEngine.inputMethod` 注入/兜底覆盖（无论布局 createInputMethod 解析到谁都换成我们）+ `handwritingModeDisabled=false`。
- `src/ui/components/HwrTestDialog.qml`：手写识别测试弹窗（自绘 Canvas + 抬笔 380ms 自动识别、top-5 候选+置信度+耗时），入口在 SystemInfoDialog → 新增信号 `hwrTestRequested()` → Main.qml 打开。
- `AI/rec.onnx`、`AI/ppocrv5_dict.txt`：从 build/AI 拷回源码目录（CMake `file(COPY AI)` 部署）。
